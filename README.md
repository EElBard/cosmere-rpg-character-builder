# Cosmere RPG — Stormlight Character Builder 🌩️

An interactive, responsive single-page character creation tool for the **Cosmere Roleplaying Game** (*Stormlight Archive* ruleset by Brotherwise Games & Dragonsteel).

Built with vanilla HTML, modern CSS, and JavaScript.

---

## ✨ Features

- **Character Concept**: Name, concept description, motivation/purpose, and personal obstacle.
- **Ancestry & Forms**: Choose between Human or Singer (including Workform, Warform, Nimbleform, and Mateform).
- **13 Rosharan Cultures**: Select 2 cultures (Alethi, Azish, Thaylen, Veden, Unkalaki, etc.) with custom cultural expertises and languages.
- **All 6 Heroic Paths**: Agent, Envoy, Hunter, Leader, Scholar, and Warrior with their unique starting Key Talents and specialties.
- **126 Complete Talent Trees**:
  - Full specialty talent trees for all 6 Heroic Paths (Investigator, Spy, Thief, Diplomat, Faithful, Mentor, Archer, Assassin, Tracker, Champion, Officer, Politico, Artifabrian, Strategist, Surgeon, Duelist, Soldier, Shardbearer).
  - All 10 Radiant Surges (Adhesion, Gravitation, Division, Abrasion, Progression, Illumination, Transformation, Transportation, Cohesion, Tension).
  - Live prerequisite checking (skill ranks, attributes, and dependent talents).
  - Level progression selector (Levels 1–10) with real-time talent point budget management.
  - Universal "Browse Talent Trees" modal view accessible from anywhere.
- **Point-Buy Attributes & Live Derived Stats**:
  - 12-point buy across Strength, Speed, Intellect, Willpower, Awareness, and Presence.
  - Live calculations for Physical Defense, Cognitive Defense, Spiritual Defense, Health, Focus, and Movement.
- **18 Core Skills**: Distribute 10 ranks with automated path skill bonuses and modifier math.
- **Starting Equipment Kits**: Academic, Artisan, Courtier, Military, Underworld, and Prisoner kits.
- **Radiant Path & Ideals**: Swear Ideals, select from all 10 Radiant Orders, and bond Spren.
- **Full Character Sheet Summary**:
  - Printable character sheet layout.
  - JSON export for digital backups and virtual tabletops.
  - LocalStorage auto-save so you never lose progress.
